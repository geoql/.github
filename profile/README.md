<h3 align="center">Open-source maps and code-quality tools for Vue and Nuxt</h3>

<p align="center">
  MapLibre GL components and plugins, Apple MapKit for Vue, and an auditor that catches bad Vue and Nuxt code.
</p>

---

**Maps for Vue**

- **[v-maplibre](https://github.com/geoql/v-maplibre)** — 50+ Vue 3 components for MapLibre GL: deck.gl, LiDAR, COG and spatial indexing. [Docs](https://v-maplibre.geoql.in) · [mapcn-vue](https://mapcn-vue.geoql.in)
- **[v-mapkit](https://github.com/geoql/v-mapkit)** — 18 Vue 3 components for Apple MapKit JS. [Docs](https://v-mapkit.geoql.in)

**MapLibre GL JS plugins**

- [maplibre-gl-wind](https://github.com/geoql/maplibre-gl-wind) — wind particle layer
- [maplibre-gl-interpolate-heatmap](https://github.com/geoql/maplibre-gl-interpolate-heatmap) — IDW interpolated heatmap layer
- [maplibre-gl-inspect](https://github.com/geoql/maplibre-gl-inspect) — inspect control
- [maplibre-gl-starfield](https://github.com/geoql/maplibre-gl-starfield) — Three.js starfield skybox
- [maplibre-gl-draw-circle](https://github.com/geoql/maplibre-gl-draw-circle) — draw and edit a circle
- [maplibre-gl-compare](https://github.com/geoql/maplibre-gl-compare) — swipe-style map comparison
- [maplibre-gl-snow](https://github.com/geoql/maplibre-gl-snow) — WebGPU snow particle layer

**Code quality for Vue and Nuxt**

- **[doctor](https://github.com/geoql/doctor)** — CLIs and oxlint plugins that audit Vue 3 and Nuxt 4 apps for performance, correctness, security and AI-agent anti-patterns. [the-doctor.report](https://the-doctor.report) · [Docs](https://docs.the-doctor.report)
- **[doctor-action](https://github.com/geoql/doctor-action)** — run the doctor in GitHub Actions.

**Agent tooling**

- **[mdr](https://github.com/geoql/mdr)** — persistent layered memory for coding agents. [mdr.geoql.in](https://mdr.geoql.in)
